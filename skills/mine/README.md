# Mine

Personal workflow skills maintained on the `mine` branch. They are isolated
from upstream-owned buckets so upstream commits can continue to be cherry-picked
without modifying the source skills they own.

## User-invoked

- **[distill](./distill/SKILL.md)** — Turn a window of real work into durable
  lessons and skill changes.
- **[session-recap](./session-recap/SKILL.md)** — Reconstruct one work-day from
  local and TMates session evidence, then optionally backfill a daily note.
- **[vivaldi-tab-tidy](./vivaldi-tab-tidy/SKILL.md)** — Safely consolidate a
  Vivaldi Workspace with verified state snapshots and conservative deduplication.
